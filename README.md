# 三角洲行动 · 物资价格榜（DeltaForce Priceboard）

一个本地运行的《三角洲行动》游戏物资比价工具：拉取第三方站点的物资价格数据，按**单位格价值**排序，支持按地图查看与阈值筛选，并对多源数据的口径做归一与校验。

> 面向单人本地使用，不提供公网服务。数据来自第三方站点接口，请遵守其使用条款。

---

## 功能

- **单位格价值排序** —— 把「价格」换算成「每格价值」，让不同占格数的物资可以横向比较
- **多地图 / 阈值筛选** —— 按地图查看，按价值区间过滤
- **数据口径归一** —— 重复物资按部位、耐久档位归并；同名的多版本物资分开统计
- **官方参考价 vs 实时成交价对照** —— 抽检比对两者偏差，不把官方价直接当作价格源
- **来源可追溯** —— 每条物资的来源标注（provenance）可查，缺失产地的物资人工补充并持久化
- **按需刷新 + 失败冷却** —— 拉取失败后进入冷却期，避免连续打接口

## 快速开始

```bash
npm install

# 复制环境变量模板并按需填写
cp get-data/.env.example get-data/.env

# 同时启动 API 与前端
npm run dev

# 或分别启动
npm run dev:api    # 后端
npm run dev:web    # 前端
```

其他常用脚本：

```bash
npm test          # 跑全部测试
npm run typecheck # 全量类型检查
npm run build     # 构建前端
npm run fetch     # 拉取一次数据
npm run refresh   # 手动刷新（绕过失败冷却）
```

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items` | 主接口，返回物资列表，顺带触发按需刷新 |
| GET | `/api/meta` | 筛选器选项 + 数据源状态 |
| GET | `/api/sources` | 各数据源健康状态 |
| GET | `/api/health` | 存活与数据新鲜度（刻意不触发抓取） |
| GET | `/api/daily` | 每日地图密码 |
| POST | `/api/refresh` | 手动刷新（绕过失败冷却，仍有最小间隔与单飞保护） |

## 数据处理上踩过的坑

这部分是这个项目里最有价值的部分，记录在 `docs/source-recon.md` 与 `get-data/overrides/` 中：

- **同名物资的重复统计**：6 组物资存在同名但不同部位 / 耐久档位的记录（共 13 条），必须按档位归并，否则排行榜会出现幽灵重复项
- **官方参考价不可直接作为价格源**：对 1,276 条记录抽检，官方 `avgPrice` 与实时成交价的平均绝对偏差约 **7.4%**，个别极端值达 +550.7% 与 −100.0%，因此官方价只作为参考基准而非成交价
- **手续费与挂价的关系并非单调**：游戏内挂价越高，手续费率越高，导致净收益存在封顶甚至倒挂。仓库中尝试用手工采集的样本反推该曲线，**拟合结果不理想，该方向在此终止**
- **来源标注覆盖率**：1,564 条物资中 1,294 条有价格（82.7%），来源标注覆盖 85.6%，未覆盖的部分在 `overrides/provenance-todo.csv` 中人工维护
